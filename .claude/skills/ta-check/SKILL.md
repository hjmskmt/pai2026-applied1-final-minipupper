# 理解度チェック

- 引数なし：直前に取り組んだ内容について理解度を確かめる（下の「手順」）
- 引数がテーマ：そのテーマについて確かめる（下の「手順」）
- 引数 `review`：復習期限が来た項目をテストする（下の「復習モード」）

## 手順

1. `docs/learning/progress.md` を読み、生徒のレベルと、過去に曖昧だった点を確認する
2. 質問を **3問** 作る。暗記ではなく、言葉で説明させる問いにする
   - 1問目：何をしたか・何が起きているかを説明させる（例：「スライダーを動かしてから RViz の脚が動くまでに何が起きているか」）
   - 2問目：なぜそうするのかを説明させる（例：「なぜ Fixed Frame を base_link にすると表示されたのか」）
   - 3問目：応用・予測（例：「実機につないだら /joint_states は誰が出すか。そのとき RViz の設定はどう変わるか」）
   - 過去に曖昧だった点があれば、1問はそれを確かめる問いにする
3. 質問は1問ずつ出し、生徒の答えを待つ。答えを先に言わない
4. 各回答を評価する
   - ◎ 自分の言葉で正確に説明できた / ○ だいたい合っているが抜けがある / △ 部分的・誤解がある / × 分からない
   - ○以下なら、正解をすぐ言わずにヒントを1つ出して、もう一度答えてもらう。それでも難しければ解説する
5. 最後にまとめを伝える：できていること、まだ曖昧なこと、次に意識するとよいこと
6. `docs/learning/progress.md` を更新する
   - 「チェック履歴」に日付・テーマ・各問の評価・根拠（生徒の答えの要点）を追記
   - 「スキルマップ」の該当項目のレベルと根拠を更新
   - 「苦手・誤解」「次の目標」を必要に応じて更新
   - 評価をつけた項目は、段階と「最終確認」「次回復習」を progress.md の間隔表に沿って設定する（初めて評価した項目は段階1 = 翌日）

## 復習モード（`review`）

1. 今日の日付を確認し、progress.md のスキルマップから「次回復習」が今日以前の項目を集める。期限切れが古い順に最大3項目
2. 該当がなければ「今日の復習はありません。次は〇月〇日（項目名）」と伝えて終わる
3. 各項目について **1問ずつ**、言葉で説明させる問いを出す。前回と同じ問いは避け、角度を変える（前回 ○ で抜けていた観点があれば、そこを突く）
   - 期限から大きく過ぎている項目は、易しめの問いから始める
4. 評価（◎○△×）と短いフィードバック。○以下ならヒントを1つ出して再回答を促す（評価は最初の回答でつける）
5. progress.md を更新する
   - ◎ / ○：段階を1つ上げ、次回復習 = 今日 + その段階の間隔。段階6に合格したら「卒業」
   - △：段階はそのまま、次回復習 = 今日 + 同じ間隔
   - ×：段階1に戻し、レベルを1つ下げる。次回復習 = 明日
   - 「チェック履歴」に「復習」と書いて記録する
6. 最後に、次の復習予定（日付と項目）を伝える
